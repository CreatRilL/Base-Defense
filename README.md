# Base Defense
**[RU]:**
Ваша цель:
- Пройти 10 волн
- Не предотвратить разрушение базы врагами
Игра создана по моим рисункам, которые были с похожей вселенной с другими нюансами. У меня получилось намного больше изучить и узнать. Игра является не особо серьёзным проектом, этаким опытом для меня. Почти всё, что я смог сделать - я сделал. Newgrounds будет после обновления игры. В настоящее время игра не имеет английской локализации.
*В данный момент репозиторий сделан для сбора багов, вопросов, советов и т.п. Но в скорем времени может быть появится что нибудь ещё...*
**[ENG]:**
Your goal:
- Survive 10 waves
- Try to prevent the enemies from destroying your base
The game is based on my own drawings, which featured a similar universe but with different nuances. I’ve learned and discovered a great deal in the process. This isn’t a particularly serious project—it’s more of an experiment for me. I’ve managed to implement almost everything I set out to do. A Newgrounds release will follow a future update. At the moment, the game does not have an English localization.
*At the moment, this repository is intended for collecting bugs, questions, suggestions, and the like. But before long, something else might appear here as well...*
